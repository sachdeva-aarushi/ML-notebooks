# NYC Taxi Demand & Fare Intelligence

An end-to-end machine learning and data analysis project using NYC Yellow Taxi trip data.

## Project Status

 In progress

## Objectives

- Analyze NYC taxi demand across time and locations
- Investigate factors influencing taxi fares
- Build a taxi demand forecasting model
- Build a fare prediction model
- Compare multiple machine learning approaches
- Perform model evaluation and error analysis

## Dataset

NYC Taxi & Limousine Commission (TLC) Trip Record Data.

## Structure

- `notebooks/` — analysis and experiments
- `data/` — raw and processed datasets
- `src/` — reusable preprocessing and modeling code
- `models/` — trained model artifacts
- `results/` — figures and evaluation results
